# InsightFlow: Веб-приложение для автоматизации разведочного анализа данных (EDA)


## 🚀 Overview

InsightFlow — это веб-приложение для облегчения и автоматизации разведывательного анализа данных, позволяющая сократить время подготовки данных и предоставляющей структурированные отчеты с визуализациями. Система включает автоматический анализ данных из CSV, использование RAG для добавления теоретических пояснений, интерактивный интерфейс написанный, а также специализированные AI-агенты для визуализации и генерации рекомендаций по обработке данных. InsightFlow сочетает в себе FastAPI, бэкенд, написанный на Python, и фронтенд, написанный на Vue.js, с OpenAI и  LangChain для AI-функционала.

## 🔍 Key Features

- **AI-аналитика**: Автоматическая обработка данных с использованием агентов на LangChain для генерации аналитических выводов
- **RAG-архитектура**: Использование хэндбука по прикладному анализу данных от Аккадемии Яндекса для улучшения качества ответов
- **Рабочее пространство**: Коллаборативная среда для команд
- **Визуализация**: Интерактивные дашборды и любые виды графиков
- **Обработка документов**: Анализ структурированных/неструктурированных данных в формате .csv и размером до 5 Мб

## 🛠️ Технологии

### Backend
- FastAPI (Python)
- LangChain + OpenAI
- PostgreSQL
- Weaviate/FAISS

### Frontend
- Vue.js 3

## ⚡️ Быстрый старт
### Предварительные требования
- Установленные Docker и Docker Compose.
- Ключи API для OpenAI/Claude (указываются в `.env`).

### Инструкция по установке:
**Клонируйте репозиторий:**
```bash
git clone https://github.com/your-repo/iiagents.git
cd iiagents
docker compose build
docker compose up
```

#### **Настройте окружение:**
Скопируйте .env.example в .env:
```bash
cp .env.example .env
```
Откройте .env и укажите:
- OPENAI_API_KEY=ваш_ключ
- DATABASE_URL=postgresql://user:pass@db:5432/iiagents


### Требования к данным

InsightFlow может обрабатывать только CSV-файлы размером до 5 МБ.
